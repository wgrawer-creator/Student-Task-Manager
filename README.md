# Student Task Manager Application

A Java-based console application that allows users to create, manage, and track tasks. This project demonstrates object-oriented programming, data structures, and file organization in Java.

## Features

- Add new tasks
- View all tasks
- Mark tasks as complete
- Delete tasks
- Menu-driven user interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList data structures
- VS Code
- Git & GitHub

## How to Run

1. Clone the repository
2. Open the project in VS Code
3. Compile the files:

   javac *.java

4. Run the program:

   java Main
